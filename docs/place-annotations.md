# 地名標註與政區名稱

地名採綠色點線；人物與著作維持各自的樣式。滑過地名可開啟地名資料，
或在地圖查看（未定位時明示坐標未定，不自動填入現代縣城）。

本輪是遍歷全部 809 篇 ECCP 傳記及已保存清史稿文本的規則掃描，不是全部
歷史地理辨識已完成。省名拼寫對照是地名表達層面的編輯提案，並不斷言所有
年代的轄境一致。英文 native-of 子句保留省級語境，短形式只在同一來源的
介詞語境下提出連結。同名異地仍需逐條辨認。

新地名有來源、段落、原文與狀態，但不補造坐標。人名／書名標註、英文斜體
和中文書名號內文字不被本輪地名規則覆寫。未確定的中文地理後綴組合只進入
`data/editorial/place-candidates.json`，不成為實體。地名頁可按原文搜尋候選。

`data/places.json` 保存地名表達與逐次出處；`data/catalog.json` 仍是閱讀器
索引。掃描報告在 `data/editorial/place-pass.json`。`sourceWordsChanged: 0`
指移除標註後逐段文字完全一致，而非宣稱轉寫本身毫無錯誤。

## 地圖名稱

省、府、縣名稱是獨立的有年代透明影像層，與既有界線圖使用同一來源校驗碼。
1820 年無縣界，亦不借用 1911 年的縣名。右上「政區名稱」可獨立關閉；
放大時改用細字、較密的名稱層。標籤位於轄境內的製圖位置，不代表治所。
遮疊處暫隱藏部分名稱，更近尺度提供更多標籤；裁切邊緣的小碎片可能無標籤。

範圍仍為 108–123°E、24–35°N 的長江中下游及鄰近地區，不是全國。
圖層用 CHGIS 的繁體名稱欄（缺失時保留其其他中文欄）；不翻譯或以現代縣名
覆蓋。日期是參考快照日期，不等於正在閱讀的事件年份。

製圖工具：`scripts/stage_map_labels.py`。它僅在明確重製影像時下載資料，
校驗來源、暫存矢量並於結束刪除。日常閱讀及發布不依賴外部地圖服务。
所有名稱圖及界線圖均保留 CHGIS 的來源及使用限制，非 MIT 資料。
