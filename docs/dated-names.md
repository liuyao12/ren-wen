# 姓名、稱號與文獻稱謂

`[縣名或氏族] 姓名` 是人物標頭；字、號、諡用獨立小字字段。完顏等氏族不是出生地。
完整籍貫／旗籍保存原始有據陳述；不得由縣籍推造民籍或由旗籍推造佐領。

## 四種時間不可混同

1. 事件發生時間與生卒時間。
2. 姓名或稱號有效期間：`from` 包含，`to` 不包含；null 結束為未限定，null 開始為不明而非無限古老。
3. 文獻寫成／刊行／版本時間；種類要標示。ECCP 1943 是刊行年，不是別號始用年。
4. 數位見證修改／取得时间，只用於版本管理，不充當文獻年代。

`data/name-history.json` 是逐條有來源的擴充記錄。個人名稱和稱號分开选择，
明确優先級相同而衝突時不擅自择一。只有標為 primaryPosthumous 的諡廟號可作主要稱號。
原文中的姓名永遠不隨游標改寫；時間條按已錄年代選取稱號＋姓名。
無單一年份錨點的段落不保留假定年代游標，顯示指定的預設身分；可手動選年份。

目前曾國藩為試點，年限依 ECCP 的年尺度記述，尚未表示月日精度或任職全史。
原名子城的改名年不明，不自動給定期間。QSG 版本未識別時文獻年代顯示待考。
各文獻所用的每一處姓名保留其原字形和出現位置；字／號分類異說另錄，不能無聲合併。

驗證：`python -m scripts.name_history validate`；SQLite 派生索引：`python -m scripts.name_history index-db`。
新增稱號需附原文可定位的證據。時段能通過結構驗證不等於學術覆核已完成。
