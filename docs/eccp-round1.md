# ECCP 全書第一輪：範圍與覆核

本輪保存 Wikisource 已取得清單中的 1,008 頁：809 篇傳記、193 篇參見條目和 6 篇參考資料。
原始回應、版本號、上游文字與加註文字分開保存。全書匯入不代表逐人消歧已完成。
每處身分標註仍有來源和狀態；未知人物以來源限定的簡略記錄表示，不能把候選檔案數當成確定人數。

QSG 目前為 789 個開頭定位候選，保存所在 235 卷全文。候選連結不是「已核定此人本傳」。
本紀、附傳及他人傳中的提及需分別覆核。尚無匹配不代表沒有相關本傳。

逐篇檢查正文、引文、書目、撰稿人與異名；不得刪掉難以標註的文字。
運行 `python -m scripts.round1_validate` 以檢查來源清單、完整文字與連結。
新版刊出仍需人工抽查和來源校勘，程式測試不構成史實的獨立認證。
